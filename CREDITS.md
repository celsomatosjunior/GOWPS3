# Créditos

- **RPCS3** (https://github.com/RPCS3/rpcs3), GPL-2.0-only: o emulador que este launcher comanda.
  Nenhum código do RPCS3 está copiado neste repositório; nomes de opções, formatos e mensagens
  foram conferidos no código-fonte (commit 4d5def5).
- **God of War III Remastered for PC**, de Felipe Prado (https://github.com/FelipePrado0/gow3_pc),
  GPL-2.0-or-later: inspiração para o launcher (perfil separado, diagnóstico, verificações).
  Nenhum código foi copiado nesta versão.
- **Wiki do RPCS3** (https://wiki.rpcs3.net/index.php?title=God_of_War_III): lista de seriais
  e configurações recomendadas para o jogo.
